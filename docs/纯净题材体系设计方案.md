# Super-Board 全动态纯净题材体系设计方案（v2）

## 1. 设计原则
- **逻辑第一，工程极简**：核心表极简收敛为 `stocks` + `stock_tags` + `ma_events` + `daily_limit_pool` + `daily_hot_news`，精简单文件脚本与工作流（`fetch.py` / `shard.py` / `tag_workflow.py` / `audit_workflow.py` / `news_workflow.py` / `build_db.py` / `query.py` / `serve.py`）+ `manual_overrides.json`。
- **完全全动态（彻底废除静态/动态分裂）**：不再死卡“财报 ≥ 5% 进静态”，每只股只维护 **1~4 个当下真正能拿来炒的纯净题材**（`stock_tags`），按核心度排序；主业在炒的直接入表，早已被市场抛弃的旧壳主业（如烟标/纸箱/女鞋/传统家装）退回 `stocks` 主营底色备查，不污染复盘视图。
- **唯一准入第一性原理（跨领域想象力 / 底层能力同源复用）**：允许当前营收 0% 或 1%，允许外围配套/专用或后道设备/材料/结构件（废除“后道组装/测试设备不贴下游”补丁）；只要公司产品/工艺/产线/资质/实体可向目标赛道输出，且 F10/公告/投关/互动易有实质动作，全行业一视同仁算有。
- **40 词极简归口不变**：沿用 `taxonomy.json` 的 25 赛道 + 15 跨界/字辈分组（`洁净室→芯片`、`液冷→算力`、`光模块/PCB/覆铜板→通信`、`机器人/AI应用/工业设备` 清晰归口）。
- **4 条硬剔除红线**：官方辟谣不涉及、纯买家内部赋能（如内部接 DeepSeek 写文案/客服）、纯行政/生活泛服务（盖办公楼食堂/常规供电/纯分销）、软件脏词与超 1 年无进展无催化僵尸。
- **并购重组只留筹划中**：`ma_events` 仅保留当前筹划中事项，必写 `target_name` 与 `target_l1`；已完成归入 `stock_tags`，已终止不入库。

## 2. 日常 5 条极简命令
```powershell
# 1. 同步每日开盘啦涨停梯队（优先直读 Ultra-Board，缺则独立拉）
python scripts/fetch.py market --date YYYY-MM-DD

# 2. 对指定日期或缺失股票抓完整 F10 与巨潮公告 PDF
python scripts/fetch.py evidence --date YYYY-MM-DD

# 3. 切分零截断字节分片（<=110KB/片）并跑工作流打标入库
python scripts/shard.py --date YYYY-MM-DD --prefix day_YYYYMMDD

# 4. 人工改判永久锁定（改 manual_overrides.json 后叠加生效）
python scripts/build_db.py apply-overrides

# 5. 一键查表 & 导出静态站（当日热门消息+7列全动态纯净梯队 / 全月导出 / 题材小表 / 并购清单 / 单股档案）
python scripts/query.py daily --date YYYY-MM-DD
python scripts/query.py month --month YYYY-MM --out-dir data/exports/YYYY-MM
python scripts/query.py theme --name 芯片
python scripts/query.py ma
python scripts/query.py stock --code 002081
python scripts/serve.py --export-site --days 45
```
