# Super-Board 纯净题材体系设计方案

## 1. 设计原则
- **逻辑第一，工程极简**：核心 5 张表 + `daily_hot_news` 每日热门消息表 + 精简单文件脚本与工作流（`fetch.py` / `shard.py` / `tag_workflow.py` / `news_workflow.py` / `build_db.py` / `query.py`）+ `manual_overrides.json`。
- **极简二值化（有就给，没有就别写）**：废除主营/副业/参股分量与显性排雷表，不达标或已终止直接剔除，不留冗余噪音列。
- **方案 A 零双标体系**：静态只认最新财报主营构成 **≥ 5%（或 ≥ 2 亿）**（人人平等、零特权、单股 1~4 个；25 大类口径定型：`PCB/覆铜板→通信`、`机械→工业设备`严格兜底+细分回流`机器人`等、`软件→AI应用`+垂直IT回流对应行业）；低于 5% 的近 1 年真实副业/参股与跨界/字辈题材统一归 `dynamic_tags`。
- **动态 1 年有效期与 `AI应用` 纯度闸门**：`dynamic_tags` 严格只看近 1 年（`from_date >= 复盘日前365天`），老旧公告不留僵尸标签；且 `dynamic: AI应用` 仅认独立对外商业化交付的 AI 产品/内容/服务，一刀切剔除设备产线自带 AI、端侧 AI 硬件/芯片模组与企业内部赋能降本增效。
- **并购重组只留筹划中**：`ma_events` 仅保留当前筹划中事项，必写重组对象（`target_name`）与目标大类（`target_l1`）；已终止视为没有，不入库。

## 2. 日常 5 条极简命令
```powershell
# 1. 同步每日开盘啦涨停梯队（优先直读 Ultra-Board，缺则独立拉）
python scripts/fetch.py market --date YYYY-MM-DD

# 2. 对指定日期或缺失股票抓完整 F10 与巨潮公告 PDF
python scripts/fetch.py evidence --date YYYY-MM-DD

# 3. 切分零截断字节分片（<=110KB/片）并跑工作流打标入库
python scripts/shard.py --date YYYY-MM-DD --prefix day_YYYYMMDD

# 4. 人工改判永久锁定（改 manual_overrides.json 后重编译）
python scripts/build_db.py --all

# 5. 一键查表（当日热门消息+8列纯净梯队 / 全月导出 / 题材小表 / 并购清单 / 单股档案）
python scripts/query.py daily --date YYYY-MM-DD
python scripts/query.py month --month YYYY-MM --out-dir data/exports/YYYY-MM
python scripts/query.py theme --name 芯片
python scripts/query.py ma
python scripts/query.py stock --code 002081
```
