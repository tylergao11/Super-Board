# Super-Board 全动态纯净题材体系设计方案

## 1. 核心架构与设计理念

- **33 词自有纯净体系**：服务 A 股超短线复盘与接力实战，统一使用 `taxonomy.json` 定义的 **33 个标准词（23 个一级赛道 + 10 个跨界分组）**，全部细分子行业按真实产业环节穿透归口。
- **开盘啦线索对账 + 最新事实裁判**：
  - 使用开盘啦个股具体属性清单（`data/raw_kpl_concepts/*.json` + `kpl_concept_map.json`）与数据库做差异对账，一致项保持稳定，仅对差异项定向核查 F10、涨停催化原文与最新公告/互动易；
  - 数据库始终反映每只个股**截至当前的最新客观进展**：新推进至研发/试制/送样/验证的及时补齐，完成过户的并购资产并入 `stock_tags`，官方澄清或已终止/注销的同步移出并留痕于 `audit_notes`。
- **双通道准入与两轨门槛**：
  - **通道① 底层能力同源复用**：产品、工艺、产线、资质或实体可向目标赛道输出且存在研发、试制、送样、验证、产线适配、参股或供货等实质动作，全周期准入；
  - **通道② 新实控人 / 控股股东 / 产业战投映射**：已完成过户或引入具备明确产业实体的新控股方/战投，按入主方核心赛道打标；筹划阶段放 `ma_events` 实时穿透 `target_l1`；
  - **两轨门槛与长期保留**：18 个未来/成长/科技/金融/政策赛道按实质推进准入；15 个传统成熟赛道以主业占比 ≥5%（或 0→1 前沿分支/近一年打板催化）为准入基准；已核实标签长期保留，随新进展刷新 `from_date`。
- **33 词核心归口速查**（完整细则见根目录 [AGENTS.md](../AGENTS.md)）：
  - **科技硬核**：造芯/设备材料/洁净室/面板光学膜/金刚石散热→`芯片`；AIDC 机房/液冷/算力租赁/电源 BBU/云存储→`算力`；光模块/PCB/CCL/电子布/光纤/连接器/被动元件→`通信`；大模型/智能体/信创软件/端侧 AI 整机/文化传媒→`AI应用`（符合 4 大核心支柱叠加 `端侧AI`）；
  - **高端制造**：人形与工业机器人/减速器/伺服/丝杠/视觉/机床/自动化产线→`机器人`；通用与专用工业装备→`机械设备`；无人驾驶/Robotaxi/车路云/雷达/线控底盘/智驾域控→`智能驾驶`；整车/汽配/车载显示→`汽车链`；
  - **能源资源与周期**：电网/特高压/核电聚变/发电运营/独立储能电站→`电力`；锂电/光伏制造/光储充配套→`锂电光伏`；制氢/储运/燃料电池→`氢能源`；油气开采/油服炼化/燃气→`油气`；有色金属与钢铁黑色金属→`有色`；
  - **物流地产基建消费**：港口/航运/快递/跨境货运/供应链物流→`航运物流`；地产开发/物业/装修建材/家居电梯→`地产链`；水泥管材/水利路桥轨交/建筑节能/工程机械→`基建`；食饮/零售/跨境电商/文旅/纺服/家电/轻工造纸包装→`消费`。
- **常驻固有属性与临时事件暗线**：
  - **常驻固有属性**：`国企改革`、5 大经典字辈（`华/东方/龙/金/羊字辈`）及省市地域属性在展示与检索层自动常驻聚合；
  - **临时事件暗线**：政策级 `并购` 与突发新字辈在消息与盘面双印证下动态激活，3 日窗口自动退潮。

## 2. 极简数据层与移动端「文艺复兴」复盘界面

- **核心表结构**：`stocks`、`stock_tags`、`ma_events`、`daily_limit_pool`、`daily_hot_news`、`daily_stock_driver`，配合单文件脚本（`fetch.py`、`build_db.py`、`query.py`、`serve.py`、`news_workflow.py`、`driver_workflow.py`）运行。
- **移动端复盘网页（`web/`，自动部署至 GitHub Pages）**：
  - **连板梯队主屏**：支持高度轴、物理断层提示、主线热度串联、`量价` 视角（成交额/换手率/首封）、断板当日涨跌幅与核按钮识别、前 2 日断板高标追踪，以及 5 板高标补涨（`补`）与异动监控（`异`）；
  - **今日热点弹层（Hub）**：统一集成 `热门板块`（5 日连热轨迹 + 梯队骨架）、`今日催化` 与 `首板前排`（1进2 核心池）；
  - **情绪周期中枢（日期弹层）**：统一展示近 20 日高度周期柱图与当日涨停/炸板封板率、1进2/连板晋级率及核按钮反馈；
  - **核心工具与秒搜**：典籍式 4×4 `题材库`、`异动监控`、`并购重组` 与支持拼音首字母的全市场 4770 股秒搜。

## 3. 日常维护与发布命令

```powershell
# 1. 同步每日开盘啦涨停梯队
python scripts/fetch.py market --date YYYY-MM-DD

# 2. 同步当日核心股开盘啦个股属性清单与 F10/公告
python scripts/fetch.py kpl-concepts --date YYYY-MM-DD
python scripts/fetch.py evidence --date YYYY-MM-DD

# 3. 叠加人工清洗覆写（manual_overrides.json -> SQLite）
python scripts/build_db.py apply-overrides

# 4. 导出静态站点快照并推送部署 GitHub Pages
python scripts/serve.py --export-site

# 5. 常用命令行检索
python scripts/query.py daily --date YYYY-MM-DD
python scripts/query.py month --month YYYY-MM --out-dir data/exports/YYYY-MM
python scripts/query.py theme --name 芯片
python scripts/query.py ma
python scripts/query.py stock --code 002453
```
